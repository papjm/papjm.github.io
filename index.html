About me

Curiosity, persistence, and responsible disclosure.

I’m Adini Rodini Rodney, an independent security researcher and bug bounty hunter based in Nigeria. I specialize in uncovering practical, high-impact weaknesses in modern web applications and APIs, with a strong focus on authorization, authentication, and business logic.

My work goes beyond automated scanning. I study how an application is intended to behave, follow its trust boundaries, and examine the moments where user-controlled data meets sensitive actions. This approach has helped me identify more than 50 vulnerabilities across HackerOne, Bugcrowd, and private security programs.

I report findings responsibly, with clear reproduction steps, realistic impact, and useful remediation guidance. My goal is simple: help teams understand the risk, fix it confidently, and make their users safer.

Think like a user. Test like an adversary. Report like a partner.

Security focus

Where I do my best work.

I focus on the application layers where identity, permissions, sensitive data, and business processes intersect.

01 / WEB

Web application security

Testing complex user flows, session handling, input processing, and sensitive functionality for exploitable weaknesses.

02 / API

API & access control

Assessing REST and GraphQL APIs for IDOR, broken object-level authorization, privilege escalation, and data exposure.

03 / IDENTITY

Authentication & account security

Examining sign-in, verification, recovery, account lifecycle, and identity integrations for trust-boundary failures.

04 / LOGIC

Business logic testing

Finding the subtle flaws that appear when valid features are combined, reordered, or used outside their intended context.
