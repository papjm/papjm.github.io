# papjm.github.io

Personal security-research portfolio for Adini Rodini Rodney.

## Publish with GitHub Pages

1. Create a public GitHub repository named `papjm.github.io` under the `papjm` account.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Visit `https://papjm.github.io` after GitHub finishes publishing.

## Edit the site

All page structure, wording, styles, and behavior are contained in `index.html`. The profile portrait is stored at `assets/adini-rodini-rodney.webp`.
